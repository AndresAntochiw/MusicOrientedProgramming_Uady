# AUDY Interaction Flow and Interface Design

This section documents the system's interaction flow and the design of its interface screens. It includes the original sketches created on an iPad, the approved flowchart, and the mockups of the selected design.

## Interaction Flow

The user begins by entering the name of a song into the search bar. As the user types, the system displays suggestions in a dropdown menu, referred to as *predict*.

The user can proceed in two ways:

- **Select a suggestion:** The selected song is used as a reference to generate recommendations.
- **Press Enter:** The system searches for matching songs and displays a list of results. The user selects a song from this list to generate recommendations.

Recommendations are displayed alongside the reference song. When a recommendation is selected, the user can view its details and access an external music player, if a link is available.

The interaction flow also allows users to return to the home screen to perform a new search.

## System Screens and States

The mockups represent the following screens and their variations:

| Screen | Represented States |
|---|---|
| Home | Search bar and AUDY presentation. |
| Predictive Suggestions | Available songs, no suggestions found, and errors displayed within the dropdown menu. |
| Search Results | List of matching songs and no results found. |
| Recommendations | Reference song, list of recommendations, and no results found. |
| Song Details | Information about the selected recommendation and access to an external music player. |
| General Error | Generic error message with options to retry or return to the home screen. |
| Loading | Searching for matching songs, generating recommendations, and loading song details. |

When an error occurs, the **Retry** option repeats the corresponding request while preserving the search text or selected song. Errors occurring during predictive suggestions are displayed within the same dropdown menu.

## Visual Design

The interface uses white backgrounds and black text to highlight the colors of the album covers. Bebas Neue is used for the AUDY brand and certain headings, while DM Sans is used for the interface text.

The AUDY brand is displayed over a collage of overlapping real album covers. The planned animation combines subtle movements and rotations with transitions between album covers, while the brand remains stationary.

Loading states feature a vinyl record using the same collage design. The record and its circular text rotate together. Two decorative images are also included: a cat wearing headphones on the home screen and another cat on the general error screen.

All screens were designed at a resolution of 1440 × 900 pixels.

## Scope of This Version

The mockups illustrate the visual appearance of the interface and its different states; they do not represent a functional implementation of the system. The songs and album covers shown are illustrative examples and do not represent actual results generated by the recommendation algorithm.

Navigation between screens has not yet been connected. Animations have been configured in Figma, but their playback has not yet been verified. The PDF and PNG files only represent the static version of the design.
